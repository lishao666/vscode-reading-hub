# VS Code 阅读中心

> **非官方声明**
>
> 本扩展为非官方第三方工具，与腾讯、微信读书及相关内容版权方不存在隶属、合作、授权或官方认可关系。本扩展仅为用户提供本地阅读辅助能力。用户应确保其使用方式符合微信读书服务协议、适用法律及相关内容版权要求。

在 VS Code 底部状态栏按页显示用户当前账号有权访问的阅读内容。

## 使用边界

- 插件不会绕过付费、会员、订阅或账号权限，只能访问当前账号本身有权访问的内容。
- 不提供整本书批量下载、全书离线缓存、EPUB/PDF/TXT 导出、批量复制正文或公开正文接口。
- 不支持共享、公开传播或跨用户传递受版权保护的正文。
- 用户应自行承担使用第三方接口或登录信息所产生的账号安全和服务协议风险。
- 如相关权利方提出合理要求，项目维护者可能调整、限制或移除相关功能。

## 实现方式

- 微信读书相关 Skill API：获取书架、目录和阅读进度。
- 微信读书网页端登录态：按用户当前阅读行为请求必要章节；会员、购买和试读权限由服务端判断。
- VS Code 状态栏分页显示正文，支持前后翻页和切换章节。
- VS Code `SecretStorage`：保存 API Key、Cookie 和网页授权信息。
- 阅读位置保存于 VS Code 本地扩展状态；已读取章节仅缓存在当前扩展进程内，不写入文件。
- 检测到 EPUB 字体混淆产生的替换字符时，会在后台调用系统 Chrome 打开网页端阅读页面完成本地字符还原。

正文读取依赖网页端内部接口，并非面向第三方公开的正文 API，可能随服务更新而变化或失效。

完整数据处理说明见 [PRIVACY.md](./PRIVACY.md)。

## 开发运行

```bash
npm install
npm run compile
```

用 VS Code 打开本目录，按 `F5` 启动 Extension Development Host，然后运行：

1. `阅读：配置服务 API Key`
2. `阅读：登录当前阅读服务`
3. `阅读：开始阅读`

macOS 默认快捷键：`Cmd+,` 上一页，`Cmd+.` 下一页，`Cmd+Option+↑/↓` 上一章/下一章，`Control+Cmd+M` 显示或隐藏底栏正文。隐藏正文后，翻页快捷键会立即释放；可关闭 `vscodeReading.enableDefaultKeybindings` 后自行绑定。

操作按钮默认隐藏，正文默认不可点击。可在设置中开启 `vscodeReading.showControlButtons` 和 `vscodeReading.clickContentToNext`。按钮顺序为 `«  ‹  正文  ›  »`。

插件会分别记录每本书最后阅读的章节和页码。使用 `阅读：书架` 可重新选择书籍，使用 `阅读：选择章节` 可跳转章节，使用 `阅读：刷新` 可重新获取当前章节并保持当前页。

## 登录信息

执行 `阅读：登录当前阅读服务` 后，插件会打开独立的系统 Chrome 窗口。扫码登录并在网页中打开一本书、翻一页后，插件会读取该独立窗口产生的必要 Cookie 和网页授权头，并保存到 VS Code `SecretStorage`。

自动登录不会读取日常 Chrome 用户配置。扩展不记录或输出完整 Cookie、Authorization、Token、请求头或正文响应。

### 手动配置（备用）

1. 在浏览器登录微信读书网页端。
2. 打开开发者工具的 Network 面板。
3. 打开一本当前账号有权阅读的书并翻页。
4. 找到 `/web/book/read` 请求。
5. 复制该请求的 cURL，在 VS Code 执行 `阅读：配置网页登录态` 后粘贴。

登录信息相当于账号凭据，请勿分享、截图、写入文档或提交到 Git。

## 数据删除

执行 `阅读：清除登录信息和缓存` 会清除：

- `SecretStorage` 中的 API Key、Cookie 和网页登录信息；
- 本地保存的当前书籍、章节和页码；
- 扩展进程内的当前章节正文缓存；
- 当前阅读界面和临时状态。
